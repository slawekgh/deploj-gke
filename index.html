Co robi skill
01

🔨 Docker Build auto

Buduje obraz lokalnie z git commit hash jako tagiem. Przy błędzie zatrzymuje się i pokazuje logi.

02

🔍 Sprawdza GCR pyta

Weryfikuje czy Container Registry jest włączone w projekcie GCP. Jeśli nie — pyta o zgodę z należytą kurtuazją przed aktywacją.

03

📤 Docker Push auto

Pushuje obraz do gcr.io/$PROJECT/$APP:$COMMIT.

04

☸️ kubectl deploy + rollout safe

Aktualizuje deployment i czeka na rollout. Przy niepowodzeniu w 120s — automatyczny rollback.

05

🌐 LoadBalancer + External IP auto

Tworzy Service typu LoadBalancer jeśli nie istnieje. Czeka na przydzielenie External IP przez GKE.

06

✅ Pełen sukces

Wyświetla URL pod którym aplikacja jest dostępna. Bez sukcesu — nie kończy.
